# PCO v0.5 Derivation, CLI, and Clean-Break Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver rebuildable current projection and retrieval, complete the public CLI, remove every v0.4 runtime path, and pass automated plus TUI acceptance gates.

**Architecture:** Build `PCO_MEMORY` and one retrieval generation from a fixed canonical HEAD inside process-owned random directories beneath `.pco/tmp`, validate them, recheck HEAD, and publish without persistent phase state. Read paths verify derivation manifests and fall back to bounded canonical records; the final CLI is a thin dispatcher over workspace, proposal, source, derivation, and retrieval services.

**Tech Stack:** Python 3.11+, tempfile/pathlib, JSON, Markdown, Tantivy, Milvus Lite, argparse, pytest, Codex/OpenCode project-local skills.

**Spec:** `docs/superpowers/specs/2026-08-30-pco-v0.5-agent-agnostic-design.md`

## Global Constraints

- This plan depends on the canonical-core, workspace-and-skills, and proposal-and-sources plans.
- Derivations are disposable and rebuildable; no journal, attempt record, phase marker, persistent lock, resume, or orphan cleanup exists.
- `pco derive all` always builds both `PCO_MEMORY` and the retrieval index from one canonical HEAD.
- Temporary roots use `mkdtemp` beneath `.pco/tmp`; a process removes only directories it created and never scans/deletes pre-existing remnants.
- Canonical HEAD is rechecked immediately before publishing each output; mismatch returns `CANONICAL_HEAD_CHANGED` or `DERIVATION_FAILED` and never rolls back canonical data.
- `PCO_MEMORY` is read-only projection data, never imported into canonical memory; modified files are listed and not overwritten without `--discard-modified-projection`.
- Search is read-only, excludes retired current records, supports `current`, `historical`, `change`, `pattern`, and `continuity`, and uses bounded canonical fallback when the index is missing/stale/broken.
- Public CLI is exactly the section 14 surface; all Harness, checkpoint, compact, source-add, export, AFFiNE, legacy Markdown projection, context, and independent backlinks surfaces are removed.
- Release gates are `pytest -q`, `PCO_RUN_MILVUS=1 pytest -q`, `git diff --check`, clean-wheel smoke tests, and Codex/OpenCode TUI permission smoke tests.

class DerivationManifest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    kind: Literal["pco_memory", "retrieval_index"]
    source_commit: str
    profile_version: str
    files: dict[str, str]


def build_projection(repository: MemoryRepository, target: Path, source_commit: str) -> DerivationManifest:
    for stream in BUSINESS_STREAMS:
        for record in effective_current(repository, stream):
            relative = projection_path(stream, record["id"])
            write_new_file(target / relative, render_business_markdown(record))
    manifest = manifest_for_tree(target, kind="pco_memory", source_commit=source_commit,
                                 profile_version=repository.profile.version)
    write_json(target / "manifest.json", manifest.model_dump(mode="json"))
    return manifest

def search(*, repo_root: Path, query: str = "", mode: str = "current", limit: int = 10,
           indexes_root: Path | None = None, start: str | None = None, end: str | None = None) -> dict[str, Any]:

        documents = bounded_canonical_documents(repository, mode=mode, maximum=CANONICAL_FALLBACK_CANDIDATES)
        status = "fallback"
    else:
        documents = generation.documents()
        status = "current"
    return rank_documents(documents, query=query, mode=mode, limit=limit, derivation_status=status,
                          start=start, end=end)

```python
def derive_all(workspace: Workspace, *, discard_modified_projection: bool = False) -> dict[str, Any]:
    source_commit = workspace.repository.head()
    conflict = verify_existing_projection(workspace.paths.projection)
    if conflict.modified and not discard_modified_projection:
        raise projection_modified(conflict)
    process_root = Path(tempfile.mkdtemp(prefix="derive-", dir=workspace.paths.tmp))
    try:
        projection_tmp = process_root / "PCO_MEMORY"
        index_tmp = process_root / "index"
        build_projection(workspace.repository, projection_tmp, source_commit)
        build_retrieval_generation(workspace.repository, index_tmp, source_commit)
        verify_projection(projection_tmp, expected_commit=source_commit)
        verify_generation(index_tmp, expected_commit=source_commit)
        ensure(workspace.repository.head() == source_commit, "CANONICAL_HEAD_CHANGED", "derive",
               "Canonical HEAD changed before publication", canonical_changed=False, retry_safe=True,
               recovery=["Run pco derive all again"])
        publish_projection(projection_tmp, workspace.paths.projection, discard=discard_modified_projection)
        ensure(workspace.repository.head() == source_commit, "CANONICAL_HEAD_CHANGED", "derive",
               "Canonical HEAD changed before index publication", canonical_changed=False, retry_safe=True,
               recovery=["Run pco derive all again"])
        publish_generation(index_tmp, workspace.paths.indexes, source_commit)
        return {"ok": True, "source_commit": source_commit, "projection": "current", "index": "current"}
    finally:
        shutil.rmtree(process_root, ignore_errors=True)
```

Publication may leave old/missing/mixed derivations if interrupted; their embedded hashes make this detectable. Do not add persistent state or concurrency support.
