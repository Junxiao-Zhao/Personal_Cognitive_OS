# PCO v0.5 Proposal and Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the human-reviewable Markdown proposal workflow, immutable input snapshot, deterministic receipt/digests, atomic canonical commit, source snapshots, and non-canonical proposal archive.

**Architecture:** A focused `pco.proposals` package separates manifest models, Markdown mapping, bounded material reading, closed-tree capture, digest construction, and orchestration. Read-only scaffold/validate never mutate; commit captures one immutable snapshot under the canonical lock, translates it to mem-core operations, commits once, releases the lock, then independently attempts a hash-checked archive rename and derivation.

**Tech Stack:** Python 3.11+, Pydantic 2, strict PyYAML loader, hashlib, difflib, pathlib/os descriptor APIs, mem-core application transactions, pytest.

**Spec:** `docs/superpowers/specs/2026-08-30-pco-v0.5-agent-agnostic-design.md`

## Global Constraints

- This plan depends on both canonical-core and workspace-and-skills plans.
- At most one active `PCO_PROPOSALS/<review_id>` exists; `.committed` is excluded.
- Scaffold and validation are read-only and do not reserve IDs or create files.
- Constructing `ProposalService`, status, scaffold, and validation leave `.pco/tmp` unchanged; only commit may create a temporary mem-core application worktree, which is removed on success or deterministic duplicate retry.
- The manifest is the closed set for business Markdown and `inputs/` artifacts; no partial commit or caller file list exists.
- Normalize material bytes exactly: optional UTF-8 BOM removal, strict UTF-8, reject UTF-16/32 BOM and NUL, preserve Unicode/whitespace, CRLF/CR to LF, append one LF only when nonempty and missing, preserve extra trailing LFs.
- `MAX_INPUT_MATERIAL_BYTES = 16_777_216`; `MAX_IMMUTABLE_SNAPSHOT_BYTES = 67_108_864`; enforce while streaming.
- Local material is a no-follow regular file, opened once, identity-checked before/after reading; unsafe entries fail.
- Agent-authored source `content_hash` and `snapshot_ref` are forbidden; PCO generates them from the captured normalized bytes.
- Receipt ID is deterministic from framed `workspace_id` and `review_id`; input, proposal, and transaction digests obey section 7.5 exactly.
- A prior `input_digest` is only a replay warning; no-op additionally requires equal proposal semantics and equivalent current records.
- Canonical success is independent of archive and derivation outcomes.
- Proposal archival has no journal or cleanup state machine and never deletes committed proposals.

```python
def frame(value: bytes | str) -> bytes:
    data = value.encode("utf-8") if isinstance(value, str) else value
    return len(data).to_bytes(8, "big", signed=False) + data


def receipt_id(workspace_id: str, review_id: str) -> str:
    digest = hashlib.sha256(b"pco-v0.5-proposal-commit\0" + frame(workspace_id) + frame(review_id)).hexdigest()
    return "commit_" + digest
```

```python
def commit(self, review_id: str) -> dict[str, Any]:
    existing = self.repository.find_receipt(self.workspace.identity().workspace_id, review_id)
    if existing is not None:
        return self._finish(existing, archive_committed_proposal(self.paths, existing))
    with self.repository.lock():
        existing = self.repository.find_receipt(self.workspace.identity().workspace_id, review_id)
        if existing is not None:
            canonical = existing
        else:
            snapshot = self._capture_for_commit(review_id)
            validated = validate_snapshot(snapshot, self.workspace, require_hashes=True)
            request = build_commit_request(self.workspace, snapshot, validated)
            if isinstance(request, SemanticNoOp):
                return request.as_result()
            canonical = self.manager.commit_application(request, lock_held=True)
    archive = archive_committed_proposal(self.paths, canonical["transaction"]["receipt"])

    return commit_result(canonical, archive, derivation)
```

def source_diff(workspace: Workspace, source_id: str | None = None) -> dict[str, Any]:
    revisions = selected_current_sources(workspace.repository, source_id)
    return {"ok": True, "sources": [diff_one_source(workspace, revision) for revision in revisions]}


def diff_one_source(workspace: Workspace, revision: dict[str, Any]) -> dict[str, Any]:
    if not revision["payload"]["locator"].startswith("file:"):
        return {"source_id": revision["id"], "refresh_required": True}
    previous = load_verified_blob(workspace.repository, revision["payload"]["snapshot_ref"])
    current = read_regular_file(file_uri_to_path(revision["payload"]["locator"]), limit=MAX_INPUT_MATERIAL_BYTES)
    return {"source_id": revision["id"], "current_content_hash": current.content_hash,
            "diff": "".join(difflib.unified_diff(previous.decode().splitlines(True),
                                                    current.normalized_bytes.decode().splitlines(True)))}
