# PCO v0.5 Workspace and Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize and verify a dedicated, safe, Agent-agnostic PCO workspace containing immutable canonical identity and two project-local SKILLs.

**Architecture:** Replace Hydra/runtime-state workspace configuration with a fixed v0.5 layout object. Initialization performs final-component no-follow checks, atomically claims `.pco`, initializes the canonical Git repository with `workspace.json` in its root commit, and copies hashed SKILL resources; all later compatibility and integrity checks are read-only.

**Tech Stack:** Python 3.11+, pathlib/os descriptor APIs, importlib.resources, Pydantic 2, packaging.specifiers, Git CLI, pytest.

**Spec:** `docs/superpowers/specs/2026-08-30-pco-v0.5-agent-agnostic-design.md`

## Global Constraints

- This plan depends on `2026-08-30-pco-v0.5-canonical-core.md`.
- `pco init [PATH]` defaults to the current directory and accepts only a nonexistent path or an empty real directory.
- The final target component is checked with `lstat` and never followed when it is a symlink.
- A file, FIFO, socket, device, symlink, or other special target returns `WORKSPACE_PATH_UNSAFE` without mutation.
- Initialization atomically claims `.pco`; a losing initializer returns `WORKSPACE_INIT_RACE`, writes nothing else, and removes nothing.
- Partial initialization is not repaired or cleaned automatically; the user removes it or chooses another path.
- Canonical identity is stored at `.pco/canonical/workspace.json`, created in the initial canonical Git commit, immutable, and preserved by full-repository restore.
- Exact bundled versions start at `0.5.0`; supported v0.5 ranges are `>=0.5.0,<0.6.0`.
- Project-local SKILLs live only at `.agents/skills/pco-memory` and `.agents/skills/pco-consolidate`; no home, global, shared-root, export, refresh, or repair path exists.
- Implement SKILL resources with the `writing-skills` sub-skill and verify Codex/OpenCode discovery in the dedicated workspace.

```python
@dataclass(frozen=True, slots=True)
class WorkspacePaths:
    root: Path
    canonical: Path
    indexes: Path
    tmp: Path
    proposals: Path
    projection: Path
    skills: Path

                   root / "PCO_PROPOSALS", root / "PCO_MEMORY", root / ".agents/skills")
```

```python
def verify_skill_tree(path: Path, package_version: str) -> dict[str, Any]:
    manifest = json.loads((path / "manifest.json").read_text(encoding="utf-8"))
    ensure(Version(package_version) in SpecifierSet(manifest["requires_pco"]),
           "WORKSPACE_SKILL_INVALID", "verify", "Installed PCO package is outside requires_pco")
    observed = {entry.relative_to(path).as_posix(): sha256_file(entry)
                for entry in regular_files_no_follow(path) if entry.name != "manifest.json"}
```

- [ ] **Step 3: Implement safe target inspection and atomic claim**

```python
@contextmanager
def claim_workspace(target: Path) -> Iterator[DirectoryAnchor]:
    require_anchor_capabilities_before_mutation()
    stat_before = lstat_absent_or_real_directory(target)
    directory_fd = open_directory_no_follow(target, create_if_absent=stat_before is None)
    try:
        ensure_directory_identity(directory_fd, target)
        ensure_directory_empty(directory_fd)
        try:
            os.mkdir(".pco", mode=0o700, dir_fd=directory_fd)
        except FileExistsError as exc:
            raise MemError("WORKSPACE_INIT_RACE", "init", "Another initializer claimed .pco") from exc
        yield DirectoryAnchor(directory_fd, expected_identity=fstat_identity(directory_fd), display_path=target)
    finally:
        os.close(directory_fd)
```

`DirectoryAnchor.mkdir(relative)`, `open_directory(relative)`, `write_bytes(relative, content)`, and `git_cwd(relative)` reject absolute paths and `..`, use `dir_fd`/`openat` with `O_NOFOLLOW`, and retain opened child directory descriptors. `git_cwd` returns a descriptor-backed subprocess working directory and the descriptors to pass to the child; it must not reconstruct `display_path / relative`. Before every major initialization stage and before success, compare the final target path identity with the anchor. A changed target returns `WORKSPACE_INIT_RACE`; every prior byte remains under the originally opened directory, never under its replacement. Do not remove `.pco` on exception. On platforms without equivalent no-follow, stable-identity, descriptor-relative creation, and descriptor-backed Git working-directory operations, raise `WORKSPACE_PATH_UNSAFE` before creating the target or `.pco`.

```python
def init_anchored(
    self,
    root: DirectoryAnchor,
    *,
    copy_profile: bool = True,
    initial_files: Mapping[str, bytes] | None = None,
) -> str:
    root.mkdir("profiles")
    if copy_profile:
        copy_profile_tree_anchored(root.open_directory("profiles"), self.profile)
    for relative, content in sorted((initial_files or {}).items()):
        root.write_bytes(self.profile._safe_relative(relative, phase="init"), content)
    git = AnchoredGit(root.git_cwd("."))
```

```python
def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="pco")
    commands = parser.add_subparsers(dest="command", required=True)
    init = commands.add_parser("init")
    init.add_argument("path", type=Path, nargs="?", default=Path.cwd())
    commands.add_parser("doctor")
    verify = commands.add_parser("verify")
    verify.add_argument("--path", type=Path)
    return parser
```
